
# Aval Safety – AI-Powered Women’s Safety Platform

Aval Safety is an AI-powered women’s safety platform designed to provide **real-time assistance, emergency support, safer route guidance, location-based safety features, and intelligent AI assistance** in critical situations.

The platform combines **Artificial Intelligence, location services, maps, emergency response features, and a user-friendly web interface** to create a smart and accessible safety solution.

### Key Features

* 🤖 AI-powered safety assistant
* 🚨 Emergency/SOS assistance
* 📍 Real-time location support
* 🗺️ Safer route and navigation guidance
* 👥 Volunteer/community support
* 🔐 Secure user authentication and profile management
* 📢 Safety alerts and notifications
* 💬 Intelligent conversational assistance

### Technology Stack

**Frontend:** React.js
**Backend:** Node.js / Express
**AI:** AI-powered conversational assistance
**Database:** MangoDB
**Maps & Location:** Maps/Geolocation APIs
**Development Tools:** VS Code, Git & GitHub

### Objective

To develop an intelligent, accessible, and technology-driven safety ecosystem that can assist women during emergencies and help them make safer decisions in real time.
